# Sistema RH 

Projeto  desenvolvido para um sistema RH do Supermercado Central das Carnes
## 🚀 Tecnologias

* Java
* Spring Boot
* Spring Data JPA
* Maven
* Lombok
* Docker

## 📚 Conceitos abordados

* CRUD (Create, Read, Update e Delete)
* Controller
* Service
* Repository
* Model
* Containers(Docker)
* Converter
* Arquitetura em camadas
* API REST
